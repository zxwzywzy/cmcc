## 数据准确性

站点 ID 匹配后才计算剩余站数，排除已过目标站的车辆。重复站点导致车辆位置不唯一时显示待确认，不任意选择一个位置。`fetchedAt` 表示本机查询时间，不是车辆 GPS 采集时间。

没有伪造公交经纬度、米数、到站分钟数、账号、余额或订单。`GetLinePlanInfos` 属始发计划，不冒充本站 ETA。站序图没有街道底图，不标作精确 GPS 地图。

## 小米真机复核步骤

1. 下载 APK 覆盖安装，打开后按线路选一条正在运营的公交与候车站，对比公众号的方向、车牌和当前站点。
2. 打开线路详情，检查站序、候车站和车辆节点；在重复站点线路确认没有猜测车辆所在位置。
3. 分别添加三种桌面组件，改变尺寸，点线路、刷新、换向和去微信乘车；大字号、深浅色各查看一次。
4. 开启候车 15 分钟并允许通知，回到桌面查看查询时间，测试通知停止按钮及到期退出。
5. 断网后主动刷新，检查仍保留上次成功数据并显示待更新。恢复网络后再刷新。

这些设备步骤是待验证项目，不是已通过记录。后台时间受 Android 与小米系统控制，不把目标频率宣传成保证频率。

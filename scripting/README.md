# Scripting 项目

每个文件夹是一个独立项目。

| 项目 | 用途 | 源码 | 安装包 |
|---|---|---|---|
| 运营商组件 | 话费、流量及账户组件 | [carriers](carriers/) | [下载](../packages/carriers.zip) |
| 武胜公交 | 实时公交、行程规划、乘车码 | [wusheng-bus](wusheng-bus/) | [下载](../packages/wusheng-bus.scripting) |

新项目统一使用 `scripting/<英文短名>/`，由项目自己的 `script.json` 管理。

# 运营商余量 · Scripting

在同一个桌面小组件里查看中国移动、联通、电信和广电的余额、剩余流量、语音。基于 MaYIHEI 的 CMCC 2.1.2 扩展，界面沿用系统列表与简洁数字卡片。移动保留原组件的 12 种样式；另外三家使用统一余量卡片。

## 安装

1. 在 iPhone 下载 https://raw.githubusercontent.com/zxwzywzy/cmcc/main/packages/carriers.zip ，通过“共享”导入 Scripting。也可在 Scripting 的导入功能中使用该 ZIP 地址。此包是新脚本“运营商余量”，不替换原“中国移动”。
2. 圈 X 的重写资源添加 https://raw.githubusercontent.com/zxwzywzy/cmcc/main/Carrier-Hub-Cookie.conf ，关闭资源解析器，开启重写与 MITM，安装并完全信任证书。已添加 Paperclip 全集时先停用它，避免与移动抓取规则重复。
3. 与原组件一样需要圈 X 上已安装并启用 BoxJS。BoxJS 官方项目：https://github.com/chavyleung/scripts/tree/master/box ，按其 Quantumult X 指引安装；代理运行时应能访问 https://boxjs.com 。不要公开 BoxJS 数据。
4. 移动：划掉 App 后重新打开，触发登录凭据抓取。联通：刷新 App 首页的余额/余量。电信：进入套餐/余量页，触发 qryImportantData。广电：刷新账户余量页，触发 qryUserInfo；App 未使用此接口时无匹配，不能保证成功。
5. 在 Scripting 运行“运营商余量”，点“从 BoxJS 导入”。此操作将圈 X 本地的数据读入本机 Keychain，未上传 GitHub。不需要把 Cookie 发给任何人。
6. 导入完成后关闭抓取订阅，桌面添加 Scripting 小组件并选择“运营商余量”。原有默认样式、样式库、外观与参数已恢复：参数留空按样式库默认值显示移动组件；可直接填“全景”“账单卡 1234”“D 1234”。四家概览请填“总览”；单独查其他运营商填“联通”“电信”“广电”。

移动原有样式参数：`移动 全景 1234`、`移动 账单卡 1234` 等（1234 为尾号）。手机中只导入移动时，其他运营商显示未导入，不会混用移动凭据。

## 可用范围和限制

这是 0.1.5 适配试用版，不是四家都已真机验证的成品。已完成解析、存储、导入与查询代码；运营商版本和证书固定可能影响抓取。联通/电信依据公开实现编写，广电 App 的路径与返回仍需验证。只有广电小程序有公开字段参考。

移动使用原查询/续登逻辑。联通、电信、广电仅重放已抓到的白名单只读查询请求；不自动登录或续期。签名、时间戳或登录会话失效时需重新抓取并导入。缺少正文或关联不到请求时保留快照，在界面标记并显示抓取时间，不伪装为实时数据。不添加签到功能。

- 移动保留原多账号及尾号样式参数；另外三家各保存最近一次抓取的一个账户，暂不提供多账号。
- 电信卡片显示通用剩余流量；其他三家的流量字段口径按各自接口，不承诺套餐口径一致。
- 缺失数值显示“—”，不会转成零；没有可信总量时不画百分比，不计算预测或倒计时。
- 刷新策略为约 2 小时，实际调度由 iOS 决定，不保证准点。小组件会显示数据时间；网络失败显示缓存。
- 凭据保存到 Scripting Keychain；圈 X 中原抓取记录仍保留，删除 Scripting 的账户不会删除圈 X 源记录。原来的广电抓取 v1 只有鉴权请求，没有可显示的余额，需要用本版重新抓取查询响应。
- 0.1.1 恢复原“小组件 / 账号 / 设置”页面与样式库，新增“运营商”页面；设置中的检查更新已指向本仓库。0.1.0 没有更新按钮，需要导入新版；重新导入可能清空组件隔离数据，届时从 BoxJS 重新导入账号。不要先删除旧脚本。

## 0.1.1 修复

恢复移动原有 12 种样式、预览、外观和默认参数；不再强制加“移动”前缀。四家概览改为显式“总览”，原样式保持默认。其他三家仍为余量卡片，并没有获得虚构的套餐总量或预测数据。

## 0.1.2：跨运营商导入与总览修复

原“账号”页的导入按钮现在同时导入四家数据，与“运营商”页共用逻辑；结果列出实际导入的运营商名称。移动账号列表仍只列移动号，其他三家的数据请在“运营商”页核对。

大号参数“总览”显示四家状态卡片，未导入的显示提示。中号不再固定截取两家，三个已导入运营商均可进入显示列表。若大号仍只有移动有数字，请先点“从 BoxJS 导入”，查看结果是否包含其他运营商；仅有旧版广电鉴权抓取记录不足以显示余量，需配套 Carrier-Hub-Cookie 订阅抓取查询响应。

从 0.1.1 升级建议在 Scripting 运行脚本，进入“设置 → 检查更新”，就地更新以保留账户。更新后再次导入，然后在“运营商”页确认所需的几家都有数据，再刷新桌面大号“总览”。真机效果仍待验证。

## 0.1.3：中号可点击切换运营商

中号参数填“总览”，上方提供移动 / 联通 / 电信 / 广电四个标签，点标签切换。下方显示所选运营商的余额、流量、语音和数据时间。选择持久保存在本脚本本机存储，各个“总览”中号实例共用该选择；不会影响移动原有号码翻页状态。

优先显示第一个有数据的运营商；已有选择时保留。未导入的运营商仍可点开，会显示导入提示。只有“总览 / 合集 / overview”的中号使用新布局，固定“联通 / 电信 / 广电”参数仍显示固定运营商；移动原样式、全景、账单卡等保持原参数行为。

在脚本“设置 → 检查更新”升级后，桌面中号组件的参数填“总览”。无需重新抓取 Cookie。交互依赖 Scripting 和 iOS 支持小组件 AppIntent；未在 iOS 真机验证。

## 0.1.4：联通、电信、广电也可设置样式

打开脚本“运营商”页，每家账户下面都有“总览样式”选择：全景 / 账单卡 / 大字余额。各家独立保存，设置后刷新桌面；中号总览标签切换到某家时，自动使用该家保存的样式。大号总览的各家卡片也分别使用其设置。

单家小组件可直接指定，例如 `联通 账单卡`、`电信 大字余额`、`广电 全景`；只填运营商名称则使用设置中保存的样式。参数指定的样式优先于默认设置。

这三种是按各家已知余额/余量数据编写的布局，名称为“全景”时只显示余额、剩余流量和语音；不包含移动原组件的完整信息、套餐百分比或用量预测。移动原有 12 种样式保持原参数规则；“运营商”页对移动的样式选择只用于总览卡片。锁屏暂保留原简洁余量布局。

升级无需重新抓取或导入。原生渲染仍待真机确认，已通过入口构建和样式配置/路由的回归测试。

## 0.1.5：中号无需填写参数

中号和大号参数留空即进入运营商总览。中号直接点击移动 / 联通 / 电信 / 广电标签切换，并应用各家保存的样式、记住选择。大号默认显示四家卡片。小号留空仍使用原移动默认样式。

已经填了“总览”的无需修改；如果之前填了固定运营商或固定样式，需要清空一次参数才能进入自动总览。明确填写的原移动样式参数仍有效，未移除样式库和账户数据。

使用“设置 → 检查更新”可就地升级。0.1.5 起更新器使用带版本号的安装包，减少下载到旧缓存包的情况。本次唯一地址为 packages/carriers-0.1.5.zip。新增空参数的中号、大号及小号兼容回归检查通过，仍待真机验证。

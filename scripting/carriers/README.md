# 运营商余量 · Scripting

在同一个桌面小组件里查看中国移动、联通、电信和广电的余额、剩余流量、语音。基于 MaYIHEI 的 CMCC 2.1.2 扩展，界面沿用系统列表与简洁数字卡片。移动保留原组件的 12 种样式；另外三家使用统一余量卡片。

## 安装

1. 在 iPhone 下载 https://raw.githubusercontent.com/zxwzywzy/cmcc/main/packages/carriers.zip ，通过“共享”导入 Scripting。也可在 Scripting 的导入功能中使用该 ZIP 地址。此包是新脚本“运营商余量”，不替换原“中国移动”。
2. 圈 X 的重写资源添加 https://raw.githubusercontent.com/zxwzywzy/cmcc/main/Carrier-Hub-Cookie.conf ，关闭资源解析器，开启重写与 MITM，安装并完全信任证书。已添加 Paperclip 全集时先停用它，避免与移动抓取规则重复。
3. 与原组件一样需要圈 X 上已安装并启用 BoxJS。BoxJS 官方项目：https://github.com/chavyleung/scripts/tree/master/box ，按其 Quantumult X 指引安装；代理运行时应能访问 https://boxjs.com 。不要公开 BoxJS 数据。
4. 移动：划掉 App 后重新打开，触发登录凭据抓取。联通：刷新 App 首页的余额/余量。电信：进入套餐/余量页，触发 qryImportantData。广电：刷新账户余量页，触发 qryUserInfo；App 未使用此接口时无匹配，不能保证成功。
5. 在 Scripting 运行“运营商余量”，点“从 BoxJS 导入”。此操作将圈 X 本地的数据读入本机 Keychain，未上传 GitHub。不需要把 Cookie 发给任何人。
6. 导入完成后关闭抓取订阅，桌面添加 Scripting 小组件并选择“运营商余量”。原有默认样式、样式库、外观与参数已恢复：参数留空按样式库默认值显示移动组件；可直接填“全景”“账单卡 1234”“D 1234”。四家概览请填“总览”；单独查其他运营商填“联通”“电信”“广电”。

移动原有样式参数：`移动 全景 1234`、`移动 账单卡 1234` 等（1234 为尾号）。手机中只导入移动时，其他运营商显示未导入，不会混用移动凭据。

## 可用范围和限制

这是 0.1.1 适配试用版，不是四家都已真机验证的成品。已完成解析、存储、导入与查询代码；运营商版本和证书固定可能影响抓取。联通/电信依据公开实现编写，广电 App 的路径与返回仍需验证。只有广电小程序有公开字段参考。

移动使用原查询/续登逻辑。联通、电信、广电仅重放已抓到的白名单只读查询请求；不自动登录或续期。签名、时间戳或登录会话失效时需重新抓取并导入。缺少正文或关联不到请求时保留快照，在界面标记并显示抓取时间，不伪装为实时数据。不添加签到功能。

- 移动保留原多账号及尾号样式参数；另外三家各保存最近一次抓取的一个账户，暂不提供多账号。
- 电信卡片显示通用剩余流量；其他三家的流量字段口径按各自接口，不承诺套餐口径一致。
- 缺失数值显示“—”，不会转成零；没有可信总量时不画百分比，不计算预测或倒计时。
- 刷新策略为约 2 小时，实际调度由 iOS 决定，不保证准点。小组件会显示数据时间；网络失败显示缓存。
- 凭据保存到 Scripting Keychain；圈 X 中原抓取记录仍保留，删除 Scripting 的账户不会删除圈 X 源记录。原来的广电抓取 v1 只有鉴权请求，没有可显示的余额，需要用本版重新抓取查询响应。
- 0.1.1 恢复原“小组件 / 账号 / 设置”页面与样式库，新增“运营商”页面；设置中的检查更新已指向本仓库。0.1.0 没有更新按钮，需要导入新版；重新导入可能清空组件隔离数据，届时从 BoxJS 重新导入账号。不要先删除旧脚本。

## 验证

在 Windows 做源码构建、规则引用检查和合成响应测试。没有 iOS Scripting 运行环境，未验证真机渲染、MITM 请求阶段和响应阶段能否同时执行、BoxJS 导入或运营商在线查询。阶段关联不成功时会退回快照模式；仍需设备实测确认。

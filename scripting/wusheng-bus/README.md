# 武胜公交 · Scripting 0.2.0 试用版

[下载 .scripting 安装包](https://raw.githubusercontent.com/zxwzywzy/cmcc/main/packages/wusheng-bus-0.2.0.scripting) · [ZIP 备用包](https://raw.githubusercontent.com/zxwzywzy/cmcc/main/packages/wusheng-bus-0.2.0.zip)

## 怎么使用

1. 在 Scripting 导入安装包并运行“武胜公交”。建议 Scripting 3.2.1 或更新。
2. 点击“用当前位置查最近站台”，允许定位并开启精确位置。默认桌面展示最近站台、直线距离、各线路到站站数、车辆上报的所在站。
3. 长按桌面添加 Scripting 组件并选择“武胜公交”，参数留空，支持小中大尺寸。点击“刷新”请求更新；iOS 决定实际刷新时间，不是连续实时地图。
4. 打开脚本的“查看站台和车辆地图”可查看自己的位置、最近站台和车辆。页面打开期间约十秒更新，离开停止；未提供车辆时不绘制虚构图钉。
5. 查余额或取乘车码前，需先在“导入私有账号”填写另行提供的口令，再选择加密账号 JSON。个人账号不在公开安装包里。
6. 点击组件“乘车码”会打开前台取码页，用真实当前位置和本机账号向公交系统请求新图；页内也有“获取 / 刷新乘车码”。取码失败可回微信使用。

更新前已装 0.1.0 的，请在 Scripting 中导入新版并确认覆盖同名“武胜公交”。当前名称与 0.0.x 的“接口准备”不同，旧准备工具可移除。

## 登录说明

目标微信小程序的流程是微信 `wx.login` 获取临时登录信息，再通过手机号授权绑定用户，最后取得鉴权 Token 与 userId。目前导入的是本人已登录微信的授权，不是另一个手机号账号，也不自动发送短信。

本版本没有独立“手机号 + 短信验证码”登录入口：已检查到的登录接口依赖微信会话、手机授权加密数据，不能把输入手机号当作登录成功。账号失效需重新导入自己的授权。账号只存本机 Keychain，列表只显示公交卡尾号。

## 位置与地图

附近站台接口已通过公共公交站经纬度验证。查询使用真实 iPhone 定位，无法定位时不伪造坐标。只保留最新一次本地位置与快照，可点击“清除本机定位缓存”删除并停用桌面定位查询。

桌面无法取得定位时，会标识上次缓存；缓存坐标超过十分钟时停止用它查询新附近站台。若移动超过100米后新查询失败，不混用旧站台车辆。定位权限不足时可打开脚本手动刷新，或在系统定位设置中检查 Scripting 权限。

蓝色图钉是自己，绿色是站台，橙色是车辆。车辆若没有已提供的经纬度，只按服务器上报的 stationNo 显示“近某站”和该站图钉，并标明“站点位置”；这是站台位置，不是车辆精确 GPS。真实非空车辆 GPS 字段与坐标系尚待设备/有车时验证。

脚本内原生地图无需地图快照功能。桌面静态地图使用 Scripting 的 MapSnapshotter PRO（需要完整版及相应 API）；没有权限或地图失败时仍显示站台距离、车辆所在站等文字，不阻止其他功能。地图不是后台实时追踪。

官方 API：[Location](https://scriptingapp.github.io/TestFlight/guide/Changelog/3.1.0/Location/) · [Map](https://scriptingapp.github.io/guide/Changelog/3.1.0/MapKit/Map/) · [MapSnapshotter PRO](https://scriptingapp.github.io/guide/Changelog/3.1.0/MapKit/MapSnapshotter/) · [Widget](https://scriptingapp.github.io/guide/Widget/Widget%20Quick%20Start)

## 乘车码：已接请求，成功出码待验证

前台每次进入/点击刷新都会清除旧图后获取真实定位，再向 `GetPayRrcode` 请求新图。只接受已适配的图片格式；不在脚本里编造乘车凭证。不自动打开页面之外的取码请求，不充值、不扣款、不绑卡。

代码仅在取码页内存中持有码图，不主动写 Storage/Keychain/文件，不上传仓库，不放入 WidgetKit 的长期快照。页面20秒后隐藏图片；这是本地显示时限，**不是官方二维码有效期**。失败不复用旧图。

本机缺少手机实时定位，用未带定位的授权请求探测时服务返回业务码500，未取得二维码图片；因此不能声称本账号已经成功出码或可刷公交机。需要 iPhone 允许真实定位后验证；失败时请在微信小程序使用。未知图片地址域名或格式会提示未适配，而不是生成替代码。

## 其他边界

- 固定线路/方向/候车站仍可选；选择后切为固定站台模式，点击定位按钮可切回附近模式。
- 前八个线路方向订阅实时通道，桌面按尺寸显示其中一至四条；仅显示有依据的站数，粗略分钟仅在速度/站距完整时推算。
- 余额只使用已核对的 cardCashfee 分单位换算为元；未返回与零分开显示，失败标记上次数据。
- 账号文件和口令请勿公开。取码能力不代表可代替官方支付或充值流程。

## 只读接口与依赖

HTTPS 主机 `https://wsapi.wskyzx.com:26110`，接口白名单：`GetBusLine`、`GetBusLineStationsByLId`、`GetBusStations`、`GetUserInfo`、`GetPayRrcode`（前台展示凭证）。车辆 `wss://wsdata.wskyzx.com:25790/ws`。没有充值/支付/退款接口。

18位 ID 用 json-bigint 保持精度。账号文件使用 PBKDF2-HMAC-SHA256（100000次）、AES-256-CBC 与 HMAC-SHA256，导入前先验证，成功才存 Keychain。第三方许可证位于 vendor；未重新分发目标小程序代码。

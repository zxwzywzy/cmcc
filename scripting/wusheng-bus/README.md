## 安装与使用

1. 在 Scripting 导入本版，覆盖同名“武胜公交”。底部为乘车码、账号、设置、组件样式；设置页应显示0.3.0。已有钥匙串登录与主题保留。
2. 登录仍沿用运营商组件：圈 X 更新公交抓取重写，微信小程序产生授权请求后，回账号页点“从 BoxJS 导入”。不用文件、不用给 BoxJS 另加应用订阅。
3. BoxJS 连接由脚本自动尝试已保存域名、boxjs.com 和 boxjs.net；验证失败不会覆盖原登录。抓取链接与检查入口在“登录与抓取”二级页。
4. 设置 → 站台与定位，允许真实定位查询最近站台，也可选择固定线路、方向和候车站。地图页打开期间约十秒更新，离开停止。
5. 桌面添加 Scripting 小组件并选择“武胜公交”，普通参数留空。小中大每页1/2/3路当前方向线路；左下刷新定位、右下换向，可翻页查看全部。
6. 组件样式页先选尺寸再选布局，各尺寸单独保存；预览使用本机已有数据，不调用乘车码接口。叠放仍可填“叠放1”…“叠放10”，手动建立同尺寸叠放，各层页码与方向独立。

## 组件休眠

默认启用组件、手动策略：平时不请求位置、HTTP、WebSocket或余额。点击刷新/定位时更新一次，随后继续休眠；组件被 iOS 本地重绘不会重复联网。

通勤策略：按手机本地时间07:00–09:00、17:00–19:30自动更新，其他时间休眠。持续策略按系统允许的节奏更新。总开关关闭后，显示关闭状态，只有显式唤醒才能恢复联网。

休眠与关闭仅限制桌面自动查询，不影响手动取码、订单或前台地图。翻页、换向不唤醒网络；请求一次后多个尺寸/叠放重绘共享短时本地保护。预计时间过期后安排一次不联网的本地重绘；实际执行时间仍由 iOS 决定。

## 预计到站与车辆位置

仅在快照近期有效、车辆仍在本站之前且完整站距与正车速均可用时计算分钟数。车辆停驶/缺速、站距缺失、位置未更新时不假设平均车速。没有车辆时显示“暂无车辆”。预计值不包含所有红灯、停站、拥堵因素。

进度条根据上报站序表示车辆前往本站的站点进度，不代表精确道路里程或套餐余量；数据不足时不画假进度。车辆米数区分“直线距本站”与“站距估算”，缺失时显示距离待更新。

最近站台仍使用真实设备定位。地图中自己的位置、站台、车辆分别标注；仅知道车辆所在站时，使用站点图钉并明确标记站点位置，不伪造车辆 GPS。

## 订单与乘车码

订单只读 `GetConsumedAndRechargeRecord`，乘车 `searchType=1`，充值 `searchType=0`，每页10条。只查询本机登录用户，先选择正确分支再规范化；金额仅用已核对的 `paymentAmount / 100`。保留未知状态码，不把未知状态强行当作成功。列表展示时间、金额、状态和线路，详情仅保留必要字段与卡/订单尾号；不保存完整响应或其中的 `qrCodeInfo`。

用户点击底部乘车码、桌面取码入口或页内刷新时，才请求一次新图及余额。普通启动、其他页签、休眠、翻页、订单查询均不取码。离开取码页或20秒后隐藏图片；该时限为本页显示限制，不是官方有效期。迟到结果与切换账号的结果会丢弃。

取码参考坐标优先使用近期本机位置，其次已知站台，否则使用已实测成功的公共站坐标。参考坐标不作为用户实际位置，不影响附近公交的真实定位。码图仅保存在页面内存，不主动写入文件、Keychain、Storage或桌面快照。未知格式报错，不生成替代码。

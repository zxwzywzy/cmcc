# 武胜公交 · Scripting 0.1.0

支持 iOS 桌面小、中、大尺寸，不需要填写组件参数。

## 安装

1. 下载 [安装包](https://raw.githubusercontent.com/zxwzywzy/cmcc/main/packages/wusheng-bus-0.1.0.zip)，在 Scripting 导入 ZIP。若导入器要求文件格式，使用同内容的 [`.scripting` 安装包](https://raw.githubusercontent.com/zxwzywzy/cmcc/main/packages/wusheng-bus-0.1.0.scripting)。
2. 运行“武胜公交”，点击“选择线路、方向和站点”，点选自己的候车站，返回首页刷新。
3. 查询公交卡余额：在“导入私有账号”填写单独提供的导入口令，再选择加密 JSON 文件。验证成功后保存本机 Keychain。不要把私有账号文件和口令上传到公开仓库。
4. 长按桌面添加 Scripting 小组件，编辑小组件并选择“武胜公交”，参数留空。已有旧版“接口准备”脚本可删除，它不是当前小组件。

账号不是安装包的一部分；其他使用者需取得自己的有效登录鉴权。本版本没有手机号验证码登录入口，也不自动抓取微信凭据。

## 功能和边界

- 可搜索线路，选择上行/下行与候车站。线路与到站查询不要求导入账号。
- 车辆站数来自实时 WebSocket。只显示目标站之前及本站附近车辆，最多三辆；服务器未返回车辆时显示“暂无车辆”。
- 有完整站距与有效速度时显示粗略预计分钟；这是位置推算，不是官方保证时间。不用模拟车辆或时刻表填补缺失数据。
- 公交卡余额只读取已确认的 `cardCashfee` 分单位，换算为元，保留尾号与查询时间；接口未返回时不显示为零。
- 乘车码仍需打开微信“武胜公交”出示。动态码有效期及签名未适配，不在桌面显示二维码。
- 组件请求约五分钟后刷新，由 iOS 决定实际时间；无法保持微信页面那样每五秒更新。临近乘车请打开脚本刷新或查询官方小程序。
- 网络失败保留上次到站或余额，并显示缓存/更新时间。账号失效需重新导入。
- 默认一个候车站、一张公交卡；不含充值、支付、绑卡、退款操作。

## 数据与安全

只读 HTTPS 查询白名单：

- `https://wsapi.wskyzx.com:26110/api/AppBusiness/GetBusLine`
- `https://wsapi.wskyzx.com:26110/api/AppBusiness/GetBusLineStationsByLId`
- `https://wsapi.wskyzx.com:26110/api/WechatInfo/GetUserInfo`

车辆推送：`wss://wsdata.wskyzx.com:25790/ws`。18 位 ID 通过 json-bigint 保持精度。

私有文件使用 PBKDF2-HMAC-SHA256（100000 次）、AES-256-CBC、HMAC-SHA256。账号导入时先验证，再保存 Keychain。Storage 只存选站、到站快照、余额与卡尾号，不存 Token 或完整账号资料。可点击“移除本机账号”清除凭据和余额缓存。

接口和协议依据本机目标小程序的只读静态核对及本人授权查询独立实现，未分发小程序原始代码。第三方依赖许可证位于 vendor。公共仓库和包中不含私有登录信息。

## 验证

`npm run build:bus` / `npm run test:bus`。测试覆盖余额单位、零与缺失值、方向过滤、站数与分钟推算、加密文件互通、错误口令/篡改拒绝、三尺寸视图结构、只读接口限制。

2026-11-11 本机实测：38 条线路，测试线路 49 个站点；本人鉴权余额查询成功且包含余额字段；车辆通道连接与订阅成功、返回空列表。测试时没有可用的非空车辆，未验证真实行驶车辆的预计时间准确性。

Windows 无 iOS Scripting 运行环境。已完成打包、数据逻辑与结构检查；原生字体间距、文件选择器、桌面刷新及设备钥匙串行为仍需 iPhone 验证。故当前为 0.1.0 试用版。

## 0.2.6：修正没有抓取通知的问题

旧订阅把 MITM 主机名写成 `wsapi.wskyzx.com:26110`，现改为 TLS SNI 主机名 `wsapi.wskyzx.com`；请求规则仍严格限制业务端口26110。该配置可能使设备未命中重写，但没有读取用户手机网络日志，不能据此断言是唯一原因。依据：[圈 X 官方 sample.conf 的 MITM 说明](https://github.com/crossutility/Quantumult-X/blob/master/sample.conf)。

抓取入口扩展为资料查询、乘车码和消费记录的请求，以及正式 `GetPhoneNumber` 登录的成功响应。只提取 Token 和 userId，不读取手机号授权请求正文，不抓取乘车码响应图片，不新增任何业务请求。只有用户自己在微信点击乘车码时才会触发该微信请求，Scripting 仍保持点击取码。

没有通知时先更新抓取订阅，在圈 X 的 MITM 主机名中确认存在 `wsapi.wskyzx.com`（无端口），确保重写、MITM 与已信任的证书生效。退出小程序并关闭微信后台，重新打开后点击“乘车码”或“消费记录”；这些入口比停留在缓存资料页更容易确认是否产生请求。已有完整授权时也可直接导入，不必等待通知。

新版登录页增加“检查抓取状态”：只读取圈 X 本地授权是否齐全和无敏感值的诊断状态。区分尚未命中、没有 Token、缺 userId、字段不识别、保存失败以及已有完整授权；状态检查不会验证登录、改账号或取乘车码。相同通知一分钟内抑制，首次成功仍及时提示。

抓取订阅与0.2.5组件兼容；新增状态检查需更新0.2.6。自动检查覆盖上述入口、登录响应ID精度、忽略乘车码响应、最小诊断记录和通知节流。实际 iPhone MITM、重写和微信通知仍需设备确认。

## 0.2.5：像运营商组件一样抓取登录

首页公交卡或“更多 → 账号管理”进入“圈 X 抓取登录”，无需账号文件、导入口令或手填 Token：

1. 沿用运营商组件已经配置好的 BoxJS、圈 X 重写与 MITM。在登录页点击“添加圈 X 抓取订阅”，确认添加并启用。本订阅只添加自己的资源，不替换已有配置；也可复制链接到圈 X 的重写资源中添加。
2. 重新打开微信“武胜公交”，如果未登录先正常完成微信手机号授权；点击乘车码或消费记录页面。
3. 收到“授权已抓取”通知后回 Scripting，点击“从圈 X 导入登录”。没有通知也可点“检查抓取状态”或直接尝试导入。默认 BoxJS 域名 boxjs.com，运营商组件使用 boxjs.net 时也可改为该域名。
4. 脚本验证授权并获取余额，成功后保存本机 Keychain。关闭本抓取订阅即可正常查余额、点击取码；授权过期后重新抓取，不需要反复抓取乘车码。

实际抓取内容是查询请求头中的 `Authorization: Bearer …` 与请求正文的 `userId`，或成功登录响应中的 token/userId，不是微信临时 code 或手机号授权的加密正文。只匹配本版本列出的特定业务路径，圈 X 本地授权键为 `wusheng_bus_login_v1`，诊断键 `wusheng_bus_login_diag_v1` 只记录版本、固定状态与时间；不保存完整请求、资料响应或二维码，不上传账户到 GitHub。

验证失败、记录缺失或连接失败不会删除旧登录。原有 Keychain 登录继续有效，旧文件不再作为界面入口。原有 BoxJS 服务不通时需先修复其重写，此脚本不会自动安装证书或改系统代理。

新增自动检查覆盖精确域名/路径、大小写请求头、24位 userId 精度、异常始终结束请求、重复通知抑制、BoxJS 读取、验证后保存及账号变化保护。iPhone 上的微信刷新 → 圈 X 抓取 → BoxJS → Scripting 全链路仍需手机验证。

## 0.2.4：点击取码，同时显示余额

只有点击首页/组件“乘车码”入口或取码页“获取 / 刷新乘车码”按钮时，才请求新码并更新余额。打开普通首页、组件定时刷新、定位、翻页、换向和地图更新均不取码。进入页面后的20秒定时器只隐藏图片，不再请求；快速重复点击合并为一轮，关闭页面后不显示迟到的结果。

取码页显示余额及更新时间：优先使用账号余额接口，单独查询失败时可采用本次成功取码返回的 `money`，按分换算为元；零余额照常显示。均不可用时保留并标注上次余额，取码失败也不会妨碍单独余额查询成功。只有余额会写本地缓存，二维码与其内容不会保存。

取码不再强制申请实时定位：使用十分钟内的本机定位缓存，其次已有站台坐标，均不可用时使用已验证的公共公交站参考坐标（30.351705, 106.303647）。这是取码请求所需的参考字段，不代表用户真实位置；附近站台和地图查询仍必须使用真实定位。

2026-11-14 本人授权实测：不带经纬度时接口返回500“用户当前位置未传入”；带公共站参考坐标时返回0“支付二维码获取成功”和 PNG data URI，图片解析成功。此结果证明本次请求能出码，不代表已验证二维码有效期、服务器所有定位校验或实际公交机扫码通过。

## 0.2.2：最近站台与底部操作

顶部显示当前最近站台，中大组件同时显示距你的直线距离与当前方向的去重线路数量。每项显示行驶方向，车辆距离与最近一辆到站车辆匹配：优先使用已提供的经纬度计算直线距离；只有车辆所在站时按完整的站间距离求“站距估算”，缺少数据则显示距离未知。估算不代表车辆当前 GPS，直线距离也不是沿道路行驶距离。

叠放：先添加多个同尺寸 Scripting 小组件并选择“武胜公交”，参数分别填 `叠放1`、`叠放2` … `叠放10`，再手动拖到一起建立系统叠放。各层默认显示不同线路页，换向/翻页分别保存；页数不足时循环。普通单个组件仍然参数留空。系统叠放操作参考 [Apple 官方说明](https://support.apple.com/en-us/118610)。脚本不会自行操作系统桌面建立叠放。

自动检查增加去重线路计数、方向循环和无服务状态、独立叠放页码、定位按钮强制请求、左右按钮位置、GPS/站距估算计算。非空实时车辆、GPS坐标系、iPhone 原生布局与系统叠放仍需设备验证。

## 怎么使用

1. 在 Scripting 导入安装包并运行“武胜公交”。建议 Scripting 3.2.1 或更新。
2. 点击“用当前位置查最近站台”，允许定位并开启精确位置。默认桌面展示最近站台、直线距离、各线路到站站数、车辆上报的所在站。
3. 长按桌面添加 Scripting 组件并选择“武胜公交”，参数留空，支持小中大尺寸。点击“刷新”请求更新；iOS 决定实际刷新时间，不是连续实时地图。
4. 打开脚本的“全部线路与地图”可查看自己的位置、最近站台和车辆。页面打开期间约十秒更新，离开停止；未提供车辆时不绘制虚构图钉。
5. 查余额或取乘车码前，在首页“圈 X 抓取登录”添加订阅，重新进入微信武胜公交的乘车码或消费记录页面，再回 Scripting 点“从圈 X 导入登录”。无需文件，个人账号不在公开安装包里。
6. 点击首页或组件“乘车码”，前台请求本次新码及余额；页内也可点击“获取 / 刷新乘车码”。只有这些点击会触发取码，不持续请求。取码失败可回微信使用。

更新前已装 0.1.0 的，请在 Scripting 中导入新版并确认覆盖同名“武胜公交”。当前名称与 0.0.x 的“接口准备”不同，旧准备工具可移除。

## 登录说明

目标微信小程序的流程是微信 `wx.login` 获取临时登录信息，再通过手机号授权绑定用户，最后取得鉴权 Token 与 userId。本脚本通过圈 X 抓取本人已登录微信的有效授权，像运营商组件一样从 BoxJS 导入；不需要提取微信临时 code。

本版本没有独立“手机号 + 短信验证码”登录入口：已检查到的登录接口依赖微信会话、手机授权加密数据。账号失效时刷新微信小程序资料并重新抓取导入即可。Scripting 账号保存在本机 Keychain，圈 X 保留本机抓取记录；列表只显示公交卡尾号。

## 位置与地图

附近站台接口已通过公共公交站经纬度验证。查询使用真实 iPhone 定位，无法定位时不伪造坐标。只保留最新一次本地位置与快照，可在“更多”点击“清除本机定位缓存”删除并停用桌面定位查询。

桌面无法取得定位时，会标识上次缓存；缓存坐标超过十分钟时停止用它查询新附近站台。若移动超过100米后新查询失败，不混用旧站台车辆。定位权限不足时可打开脚本手动刷新，或在系统定位设置中检查 Scripting 权限。

蓝色图钉是自己，绿色是站台，橙色是车辆。车辆若没有已提供的经纬度，按服务器上报的 stationNo 显示“近某站”、已知站距估算和该站图钉，并标明“站点位置”；这是站台位置，不是车辆精确 GPS。真实非空车辆 GPS 字段与坐标系尚待设备/有车时验证。

脚本内原生地图无需地图快照功能。按手机端修改，当前桌面组件采用文字卡片布局，不请求地图快照；查看地图请进入脚本“全部线路与地图”。地图不是后台实时追踪。

## 乘车码：已验证接口出图，扫码待验证

用户点击入口进入前台或点击刷新时，清除旧图后向 `GetPayRrcode` 请求新图，并查询余额。普通页面启动不取码，页面重绘和隐藏定时器均不再取码。只接受服务返回的已适配图片，不在脚本里生成替代凭证，不充值、不扣款、不绑卡。

代码仅在取码页内存中持有码图，不主动写 Storage/Keychain/文件，不上传仓库，不放入 WidgetKit 的长期快照。页面20秒后隐藏图片；这是本地显示时限，**不是官方二维码有效期**。失败不复用旧图。

已在电脑端用本人授权及公共站参考坐标成功取得 PNG 码图。iPhone 原生展示和公交机扫码通过尚待设备验证；失败时请在微信小程序使用。未知图片地址域名或格式会提示未适配，而不是生成替代码。

## 其他边界

- 固定线路/方向/候车站仍可选；选择后切为固定站台模式，点击定位按钮可切回附近模式。
- 最近站台全部有效线路方向订阅实时通道，不再限制前八个；桌面小/中/大每页显示一/二/三条当前方向线路，用翻页查看全部，同一线路不同时显示上下行；仅显示有依据的站数，粗略分钟仅在速度/站距完整时推算。车辆距离只在可匹配首辆车时显示 GPS 直线距离或站距估算，不是道路剩余里程。附近模式组件在有本机账号时查询余额，失败显示标记为上次数据的缓存。
- 账号余额使用已核对的 cardCashfee 分单位换算为元；取码响应的 money 同样按原小程序的分单位换算，只在账号余额不可用时采用。未返回与零分开显示，失败标记上次数据。
- 抓到的授权相当于登录凭据，保持在本机使用。取码能力不代表可代替官方支付或充值流程。

## 只读接口与依赖

HTTPS 主机 `https://wsapi.wskyzx.com:26110`，接口白名单：`GetBusLine`、`GetBusLineStationsByLId`、`GetBusStations`、`GetUserInfo`、`GetPayRrcode`（前台展示凭证）。车辆 `wss://wsdata.wskyzx.com:25790/ws`。没有充值/支付/退款接口。

18位 ID 用 json-bigint 保持精度；抓取脚本保留最多24位的 userId 文本，避免原生 JSON 数值精度损失。圈 X 抓取登录先向真实资料接口验证，再保存 Keychain。旧版加密文件解码仅保留兼容代码，不提供文件导入界面。第三方许可证位于 vendor；未重新分发目标小程序代码。

# 武胜公交 · 接口准备 0.0.2

这是开发准备工具，尚未接通实时到站、卡余额或乘车码。独立于运营商组件，不替换现有脚本。

1. 导入 packages/wusheng-bus-0.0.2.zip 到 Scripting 并运行。
2. 在圈 X 开启网络活动记录，再打开微信里的“武胜公交”，分别查看实时公交、余额、乘车码。
3. 将看到的业务域名填进脚本（不是小程序名称，可带端口，不含路径或参数）。看不到域名时先停止，不能猜测。
4. 复制诊断规则，将 rewrite_local 条目和 MITM 主机名分别追加到现有配置；不要覆盖已有主机名。启用重写、MITM，信任证书。
5. 再打开小程序三个页面，回脚本从 BoxJS 读取结构诊断。完成后关闭规则。

诊断仅保留业务域名、不可直接还原的接口编号（短散列用于区分接口，不是匿名化保证）、状态、凭据是否存在和固定白名单字段的类型结构。不保留原 URL 路径、查询参数、请求头内容、登录正文、响应值、二维码或实际卡余额；未知字段名也不保留。JSON 只在本机短时解析后丢弃，超过256KB不解析。记录最多60项，留在圈 X 本地。脚本不发送网络诊断、Cookie或二维码到仓库；BoxJS读取仅限 boxjs.com。

下一阶段需要实际接口证据与授权，再编写白名单只读查询适配。当前不会重放任何请求，不会触发充值、购票、开卡或支付。乘车码需验证签名、有效期和官方第三方展示支持，未适配前不显示静态替代码。若小程序绕过代理或固定证书，以上诊断可能无记录，不等同抓取成功。

公开调研确认该小程序具有实时公交查询功能，但未查到公开API，不能用历史线路时间代替实时到站。资料：https://www.wusheng.gov.cn/gasylbzj/c112145/pc/content/content_1728714808186830848.html ；https://guoqing.china.com.cn/2024-12/25/content_117628568.shtml 。

本机仅验证构建和诊断隐私逻辑；没有iPhone原生渲染或真实武胜公交接口测试。
